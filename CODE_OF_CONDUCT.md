# Code of Conduct

xBO follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, welcome newcomers, and keep discussions about the work. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests, discussions or any other project space.

Report unacceptable behaviour privately to the maintainers through a GitHub security advisory on this repository or by contacting a maintainer directly. Reports are handled confidentially, and maintainers may remove content or ban participants who break these rules.
