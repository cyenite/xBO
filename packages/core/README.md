# @xbo-ui/core

The framework-free core of [xBO](https://github.com/cyenite/xBO): window management and geometry, keyboard shortcut parsing and formatting, search ranking, OKLCH colour maths with WCAG contrast checks, theme presets and accent derivation, the preference schema and storage adapters.

Most apps use it through `@xbo-ui/vue`, which re-exports everything here. Use it directly to build another UI binding or to test window rules without a DOM.
