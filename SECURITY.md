# Security policy

## Supported versions

xBO is pre-1.0. Security fixes go into the latest release only.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub: **Security > Report a vulnerability** on this repository. Include the affected package and version, steps to reproduce, and the impact you see.

You will get an acknowledgement within a few days. Once a fix is released, the advisory is published with credit unless you prefer otherwise.
